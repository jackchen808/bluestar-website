前端客户关系与商机拓展

商务/售前

客户经理（Account Manager）

职责概述

  • 负责目标客户的开发与维护，深度理解客户IDC基础设施需求
  • 制定客户拓展计划，推进商务谈判与合同签署
  • 协调内部交付与运维团队，确保客户需求准确传达到执行端
  • 客户关系管理，定期回访，挖掘增量机会

任职要求

  • 本科及以上学历，3年以上IDC/云计算/IT基础设施行业销售经验
  • 熟悉数据中心基础设施服务业务流程
  • 具备良好的商务谈判能力和客户关系维护能力
  • 具备跨部门协调能力
客户经理 → 高级客户经理 → 客户总监 → 商务VP
商务/售前

售前技术顾问（Pre-Sales Technical Consultant）

职责概述

  • 配合客户经理进行售前技术交流
  • 现场勘察机房条件，编制勘察报告
  • 编写技术服务方案书，参与技术评审与投标答辩
  • 为商务报价提供技术依据

任职要求

  • 本科及以上学历，3年以上IDC售前或基础设施工程师经验
  • 熟悉IDC机房各系统（配电/暖通/综合布线/消防）
  • 具备方案编写能力和客户沟通能力
  • 了解主流服务器硬件架构
售前技术顾问 → 高级售前顾问 → 解决方案架构师 → 技术总监
商务/售前

解决方案架构师（Solution Architect）

职责概述

  • 针对大型或复杂项目，设计整体技术解决方案
  • 负责技术方案评审与竞品技术对标
  • 编写技术白皮书、方案建议书等技术文档
  • 参与行业技术论坛和标准制定

任职要求

  • 本科及以上学历，5年以上IDC领域技术经验
  • 精通数据中心基础设施全系统（电力/暖通/网络/消防）
  • 具备大型项目方案设计经验（500+机柜）
  • 持有PMP或高级工程师职称优先
解决方案架构师 → 首席架构师 → 技术VP

交付团队

项目执行与质量管控

交付

项目经理（Project Manager）

职责概述

  • 作为项目交付统一接口，对交付进度、质量、安全全程负责
  • 制定项目计划，协调资源，管控风险
  • 主持进度会议，编制周报/月报
  • 组织项目验收，确保交付物达标

任职要求

  • 本科及以上学历，持有PMP认证
  • 3年以上IDC/基础设施/弱电项目交付管理经验
  • 熟悉数据中心施工工艺和验收标准
  • 具备团队管理和多方协调能力
项目经理 → 高级项目经理 → 项目总监 → 交付VP
交付

现场工程师（Field Engineer）

职责概述

  • 负责服务器上架、布线、加电、测试等现场操作
  • 按SOP执行施工，确保工艺质量
  • 填写施工记录、工时记录、问题清单
  • 协助QA进行现场验收

任职要求

  • 大专及以上学历，计算机/电子/通信相关专业
  • 1年以上服务器硬件或弱电施工经验
  • 熟悉主流服务器硬件结构
  • 持有电工证或相关认证优先
现场工程师 → 高级工程师 → 现场主管 → 区域交付经理
交付

QA 验收工程师（QA Engineer）

职责概述

  • 独立于交付团队，负责项目全过程质量监督
  • 按照验收标准逐项检查施工/交付质量
  • 出具质量报告和不合格项整改通知单
  • 跟踪整改闭环并复验

任职要求

  • 本科及以上学历，3年以上IDC/IT基础设施质量管理经验
  • 熟悉ISO 9001质量管理体系
  • 原则性强，有独立判断能力
  • 持有内审员或六西格玛证书优先
QA工程师 → 高级QA → 质量总监
交付

EHS 安全员（EHS Officer）

职责概述

  • 施工现场安全监督，确保作业规范和安全规范执行到位
  • 组织每日安全早会（Toolbox Talk）
  • 安全隐患排查并推动整改
  • 安全事件记录、上报与复盘

任职要求

  • 大专及以上学历，持有安全员C证
  • 2年以上施工现场安全管理经验
  • 熟悉建筑施工安全规范和EHS管理体系
  • 持有ISO 45001内审员资格优先
EHS安全员 → 安全主管 → EHS经理 → 安全总监

运维团队

7×24 稳定运营的守护者

运维

驻场运维工程师（On-site Operations Engineer）

职责概述

  • 数据中心现场7×24值班，按SOP执行日常运维
  • 故障工单响应、诊断、处置
  • 硬件故障更换（磁盘/内存/电源等）
  • 每日机房巡检并填写巡检报告

任职要求

  • 大专及以上学历，1年以上数据中心运维经验
  • 熟悉Linux/Windows基本操作命令
  • 具备硬件故障排查和更换能力
  • 能接受轮班制（白班/夜班）
运维工程师 → 值班组长 → 运维主管 → 运维总监
运维

值班组长（Shift Leader）

职责概述

  • 带领当班团队完成运维任务
  • 重大故障升级处理和应急指挥
  • 交接班管理，确保信息同步
  • 培训和考核当班成员

任职要求

  • 大专及以上学历，3年以上数据中心运维经验
  • 具备团队管理能力
  • 熟悉ITIL流程和事件管理
  • 持有RHCE/CCNA或同等认证优先
值班组长 → 运维主管 → 运维经理 → 运维总监
运维

技术支持工程师（L1/L2/L3 Support Engineer）

职责概述

  • L1：工单响应、基础故障排查、记录上报
  • L2：OS/驱动/网络配置类故障诊断与解决
  • L3：架构级疑难故障处理，厂商协维

任职要求

  • L1：大专，1年以上IT支持经验
  • L2：本科，3年以上系统/网络运维经验
  • L3：本科，5年以上资深运维经验
  • 持有对应级别的技术认证
L1 → L2 → L3 → 技术专家 → 首席工程师
